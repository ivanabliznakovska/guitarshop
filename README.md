# Guitar shop

This is a web application built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).  
The app displays different guitar models and allows filtering, browsing, and selection.

## technologies
- [Next.js 14](https://nextjs.org/) – React framework for modern web applications
- [Tailwind CSS](https://tailwindcss.com/) – utility-first CSS framework
- GraphQL fetch helper (`app/lib/gqlFetch.js`)
- Custom React providers (`app/providers.js`)
